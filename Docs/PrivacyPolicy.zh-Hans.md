# 凤凰山谷隐私说明

生效日期：2026 年 7 月 25 日

本说明适用于当前本地版“凤凰山谷”iPad 应用。若后续版本增加云同步、在线地图、分析服务或账号系统，应在发布该版本前同步更新本说明和 App Store 隐私披露。

## 数据处理

凤凰山谷不要求登录，不接入广告、分析或跟踪服务，也不会把用户数据发送给开发者或第三方服务器。

应用会在设备上的应用容器中保存用户创建的地图资料，包括地图与分组名称、生成地形、道路几何、道路属性、主题设置以及创建和修改时间。这些资料用于打开、编辑、撤销、重做和恢复用户的地图。

Apple Pencil 或触控输入在设备上处理并转换为道路几何。当前版本不保存原始触控事件、压感、倾斜、悬停或生物识别数据。

通过 Siri 或快捷指令启动应用时，应用只接收用户选择的操作和道路类型。语音识别由 Apple 的系统服务处理；凤凰山谷不接收或保存语音录音、听写文本或 Siri 账号资料。

## 导出文件

用户可以主动将地图导出为 PNG、PDF、SVG 或 GeoJSON，并在系统文件面板中选择保存位置。导出后，文件由用户及其选定的文件提供方管理；如果用户选择 iCloud Drive 或其他第三方文件提供方，对方的隐私政策适用于该副本。

## 删除

用户可以在应用内删除地图。卸载应用会删除应用容器中的本地项目资料；已经导出到“文件”或其他位置的副本需要由用户在相应位置另行删除。

## 跟踪与第三方 SDK

当前版本不进行跨应用或跨网站跟踪，不使用广告标识符，也不包含第三方分析、广告、崩溃上报或社交登录 SDK。

## 联系方式

发布前由 App Store Connect 账号持有人填写公开支持邮箱，并将本说明部署到可公开访问的 HTTPS 地址。不要在未确认授权的情况下使用本机 Git 邮箱或其他个人联系方式。
